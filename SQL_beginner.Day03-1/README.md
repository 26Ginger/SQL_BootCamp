# Day 03 — SQL Bootcamp

## Работа с данными: JOIN и DML операции

**Цель дня:** Изучение модификации данных с помощью DML (Data Manipulation Language) и сложных JOIN-запросов.

## Упражнения

### Упражнение 00 — Поиск подходящих цен
**Задача:** Найти пиццы ценой от 800 до 1000 рублей, которые покупала Kate, с датами посещений

### Упражнение 01 — Невостребованные меню
**Задача:** Найти ID меню, которые никто не заказывал (без использования JOIN)

### Упражнение 02 — Непопулярные пиццы
**Задача:** Найти названия и цены пицц, которые никто не заказывал

### Упражнение 03 — Сравнение визитов
**Задача:** Найти пиццерии, которые чаще посещают женщины или мужчины (с сохранением дубликатов)

### Упражнение 04 — Сравнение заказов
**Задача:** Найти пиццерии, которые заказывают только женщины ИЛИ только мужчины (без дубликатов)

### Упражнение 05 — Визиты без заказов
**Задача:** Найти пиццерии, которые Andrey посещал, но не делал заказов

### Упражнение 06 — Похожие пиццы
**Задача:** Найти пиццы с одинаковыми названиями и ценами в разных пиццериях

### Упражнение 07 — Добавление новой пиццы
**Задача:** Добавить новую пиццу "greek pizza" в меню Dominos

### Упражнение 08 — Динамическое добавление
**Задача:** Добавить пиццу "sicilian pizza" с автоматическим расчетом ID

### Упражнение 09 — Новые визиты
**Задача:** Зарегистрировать визиты Denis и Irina в Dominos

### Упражнение 10 — Новые заказы
**Задача:** Зарегистрировать заказы новой пиццы от Denis и Irina

### Упражнение 11 — Изменение цены
**Задача:** Уменьшить цену "greek pizza" на 10%

### Упражнение 12 — Массовые заказы
**Задача:** Зарегистрировать заказы "greek pizza" для всех людей 25 февраля 2022

### Упражнение 13 — Откат изменений
**Задача:** Удалить новые заказы и "greek pizza" из меню

## Технические требования

- **Язык:** ANSI SQL
- **СУБД:** PostgreSQL
- **Особенности:**
  - Работа с DML операциями (INSERT, UPDATE, DELETE)
  - Использование различных типов JOIN
  - Работа с множествами (UNION, EXCEPT, INTERSECT)
  - Генерация последовательностей (generate_series)
  - Паттерн "insert-select"
- **Важно:** В упражнениях с модификацией данных предусмотрены предупреждения о возможной порче данных

**Примечание:** Все решения представлены в отдельных SQL-файлах с соответствующими названиями. Для упражнений с модификацией данных рекомендуется использовать скрипт для восстановления базы.
