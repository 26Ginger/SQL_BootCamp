# Team 01 — SQL Bootcamp
Проект был выполнен совместно с одним человеком.

## Data Warehouse и ETL процессы

**Цель дня:** Знакомство с концепцией Data Warehouse и создание первого ETL процесса для агрегации данных из разных источников.

## Упражнения

### Упражнение 00 — Классический DWH
**Задача:** Создать SQL запрос для агрегации данных о балансах пользователей с конвертацией в USD

**Источники данных:**
- `User` - информация о пользователях (Green DB)
- `Currency` - курсы валют с историей изменений (Red DB)  
- `Balance` - балансы пользователей с историей (Blue DB)

**Требования:**
- Обработать данные с аномалиями (отсутствующие связи между таблицами)
- Заменить NULL значения на 'not defined'
- Использовать последний доступный курс валюты
- Рассчитать общий объем в USD

### Упражнение 01 — Детализированный запрос
**Задача:** Найти ближайший курс валюты для каждой транзакции баланса

**Особенности:**
- Поиск ближайшего курса в прошлом
- Если в прошлом нет - поиск в будущем
- Расчет стоимости в USD для каждой транзакции

## Ключевые концепции DWH:

### Основные подходы:
- **Inmon** - нормализованный подход, сначала интеграция
- **Kimball** - dimensional modeling, сначала анализ

### Архитектура:
Data Lake + Data Warehouse = LakeHouse

### Модели данных:
- Relational, Temporal, BiTemporal
- Star/Snowflake схемы
- Data Vault, Anchor модели

## Технические особенности:

- **Несогласованность данных** - отсутствие внешних ключей между источниками
- **Временные данные** - хранение истории изменений
- **Обработка NULL** - стандартизация значений
- **Сложные JOIN** - объединение данных из независимых источников

**Примечание:** Оба упражнения демонстрируют реальные сценарии работы с данными в DWH, включая обработку аномалий и временных данных.
