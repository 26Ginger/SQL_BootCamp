# SQL Bootcamp 

## О буткемпе
Курс по SQL и базам данных от школы программирования 21, охватывающий все аспекты работы с реляционными базами данных - от основ до продвинутых тем.

## Индивидуальные проекты

### Day 00 — Основы SQL
**Изучение основ реляционной модели и базовых конструкций SQL**
- Создание и управление таблицами
- Базовые операции SELECT, WHERE, ORDER BY
- Работа с агрегатными функциями

### Day 01 — Множества и JOIN
**Работа с операциями над множествами и базовыми JOIN-операциями**
- UNION, EXCEPT, INTERSECT
- INNER JOIN, NATURAL JOIN
- Сравнение IN vs EXISTS

### Day 02 — Продвинутые JOIN
**Изучение различных типов JOIN-операций**
- LEFT/RIGHT/FULL JOIN
- Работа с CTE (Common Table Expressions)
- Сложные аналитические запросы

### Day 03 — Модификация данных (DML)
**Изучение операций изменения данных**
- INSERT, UPDATE, DELETE
- Транзакции и целостность данных
- Сложные запросы с модификацией данных

### Day 04 — Представления и материализованные представления
**Работа с виртуальными таблицами**
- Создание и использование Views
- Материализованные представления
- Оптимизация запросов через представления

### Day 05 — Индексы и оптимизация
**Улучшение производительности запросов**
- Создание B-Tree индексов
- Функциональные и многоколоночные индексы
- Анализ планов выполнения (EXPLAIN ANALYZE)

### Day 06 — Расширение модели данных
**Реализация бизнес-логики в БД**
- Система персональных скидок
- Ограничения целостности (CONSTRAINTS)
- Автоматическая генерация ключей

### Day 07 — OLAP и аналитика
**Аналитические конструкции для сводной информации**
- Агрегатные функции и GROUP BY
- Оконные функции
- Сложные аналитические запросы

### Day 08 — Транзакции и изоляция
**Управление параллельным доступом**
- Уровни изоляции транзакций
- Аномалии параллельного доступа
- Взаимные блокировки (Deadlocks)

### Day 09 — Функции и триггеры
**Процедурные расширения PostgreSQL**
- SQL и PL/pgSQL функции
- Триггеры для аудита изменений
- Бизнес-логика на уровне БД

## Групповые проекты

### Team 00 — Задача коммивояжера
**Решение классической оптимизационной задачи**
- Рекурсивные SQL запросы
- Гамильтоновы циклы
- Поиск оптимальных маршрутов

### Team 01 — Data Warehouse
**Построение ETL процессов и аналитической системы**
- Интеграция данных из разных источников
- Временные данные и история изменений
- Агрегация и преобразование данных

## Приобретенные навыки
- Проектирование и нормализация баз данных
- Сложные SQL запросы и оптимизация
- Транзакции и управление параллельным доступом
- Аналитика и бизнес-отчетность
- Процедурные расширения и автоматизация
