## Задача коммивояжера (Traveling Salesman Problem)

**Цель дня:** Реализация решения классической задачи коммивояжера с использованием SQL и рекурсивных запросов.

## Упражнения

### Упражнение 00 — Классическая задача коммивояжера
**Задача:** Найти все маршруты с минимальной стоимостью, начинающиеся из города "a" и возвращающиеся обратно

**Требования:**
- Создать таблицу с точками и стоимостями переходов
- Учесть прямые и обратные пути между городами
- Найти все возможные гамильтоновы циклы (посещение всех городов)
- Выбрать маршруты с минимальной общей стоимостью

### Упражнение 01 — Поиск максимальных маршрутов
**Задача:** Расширить решение для поиска как минимальных, так и максимальных по стоимости маршрутов

## Ключевые концепции:

### Задача коммивояжера (TSP):
- **Проблема:** Найти кратчайший маршрут через все города с возвратом в начальную точку
- **Сложность:** NP-сложная задача
- **Применение:** Логистика, маршрутизация, планирование

### Техническая реализация:
- **Рекурсивные запросы** - для генерации всех возможных путей
- **Гамильтонов цикл** - путь, проходящий через все вершины ровно один раз
- **Симметричные стоимости** - стоимость A→B = B→A

## Структура данных:

```sql
Таблица маршрутов:
- point1 (начальная точка)
- point2 (конечная точка) 
- cost (стоимость перехода)
```
