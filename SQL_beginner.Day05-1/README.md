# Day 05 — SQL Bootcamp

## Индексы в SQL: оптимизация производительности

**Цель дня:** Изучение создания и использования индексов для улучшения производительности запросов в PostgreSQL.

## Упражнения

### Упражнение 00 — Индексы для внешних ключей
**Задача:** Создать BTree индексы для всех внешних ключей в базе данных по шаблону `idx_{table_name}_{column_name}`

### Упражнение 01 — Проверка работы индексов
**Задача:** Написать запрос для вывода пицц и пиццерий, затем доказать работу индексов с помощью `EXPLAIN ANALYZE`

### Упражнение 02 — Функциональный индекс
**Задача:** Создать функциональный BTree индекс `idx_person_name` для имен людей в верхнем регистре

### Упражнение 03 — Многоколоночный индекс
**Задача:** Создать многоколоночный индекс `idx_person_order_multi` для оптимизации запроса с фильтрацией по person_id и menu_id

### Упражнение 04 — Уникальный индекс
**Задача:** Создать уникальный индекс `idx_menu_unique` для комбинации pizzeria_id и pizza_name

### Упражнение 05 — Частично уникальный индекс
**Задача:** Создать частично уникальный индекс `idx_person_order_order_date` для определенной даты

### Упражнение 06 — Оптимизация производительности
**Задача:** Создать индекс `idx_1` для улучшения производительности сложного оконного запроса

## Технические требования

- **Язык:** ANSI SQL
- **СУБД:** PostgreSQL
- **Типы индексов:**
  - **BTree** - стандартный индекс для равенства и диапазонов
  - **Функциональный** - индекс на основе выражения
  - **Многоколоночный** - индекс по нескольким колонкам
  - **Уникальный** - обеспечивает уникальность данных
  - **Частичный** - индекс для подмножества данных

## Ключевые концепции:

### Для проверки индексов:
```sql
EXPLAIN ANALYZE ваш_запрос;
```
### Отключение последовательного сканирования:
```sql
SET enable_seqscan = off;
```
**Примечание:** Все решения представлены в отдельных SQL-файлах. Для доказательства работы индексов можно EXPLAIN ANALYZE.
