# Day 08 — SQL Bootcamp

## Транзакции и уровни изоляции в SQL

**Цель дня:** Изучение транзакций, уровней изоляции и аномалий параллельного доступа к данным в PostgreSQL.

## Упражнения

### Упражнение 00 — Базовая транзакция
**Задача:** Продемонстрировать работу транзакций - изменения видны только после COMMIT

### Упражнение 01 — Аномалия "Потерянное обновление"
**Задача:** Воспроизвести аномалию "Lost Update" на уровне изоляции READ COMMITTED

### Упражнение 02 — Потерянное обновление в REPEATABLE READ
**Задача:** Исследовать поведение "Lost Update" на уровне REPEATABLE READ

### Упражнение 03 — Аномалия "Неповторяемое чтение"
**Задача:** Воспроизвести "Non-Repeatable Reads" на уровне READ COMMITTED

### Упражнение 04 — Неповторяемое чтение в SERIALIZABLE
**Задача:** Изучить поведение "Non-Repeatable Reads" на уровне SERIALIZABLE

### Упражнение 05 — Аномалия "Фантомное чтение"
**Задача:** Воспроизвести "Phantom Reads" на уровне READ COMMITTED

### Упражнение 06 — Фантомное чтение в REPEATABLE READ
**Задача:** Исследовать "Phantom Reads" на уровне REPEATABLE READ

### Упражнение 07 — Взаимная блокировка (Deadlock)
**Задача:** Создать ситуацию взаимной блокировки между двумя сессиями

## Технические требования

- **Инструмент:** Командная строка PostgreSQL (psql)
- **Формат сдачи:** SQL-файлы с комментариями + скриншоты вывода
- **Уровни изоляции:**
  - READ COMMITTED (по умолчанию)
  - REPEATABLE READ
  - SERIALIZABLE

## Ключевые концепции:

### Уровни изоляции и аномалии:

| Уровень изоляции | Потерянное обновление | Неповторяемое чтение | Фантомное чтение |
|------------------|---------------------|---------------------|-----------------|
| READ COMMITTED   | ❌ Возможно         | ✅ Защищает         | ❌ Возможно     |
| REPEATABLE READ  | ✅ Защищает         | ✅ Защищает         | ❌ Возможно     |
| SERIALIZABLE     | ✅ Защищает         | ✅ Защищает         | ✅ Защищает     |

### Основные команды:
```sql
SHOW TRANSACTION ISOLATION LEVEL;  -- Показать текущий уровень
SET TRANSACTION ISOLATION LEVEL ...; -- Установить уровень
BEGIN; -- Начать транзакцию
COMMIT; -- Зафиксировать изменения
ROLLBACK; -- Откатить изменения
```

**Примечание:** Все упражнения выполняются в двух параллельных сессиях psql. В папках скриншоты для демонстрации поведения.
