# Day 04 — SQL Bootcamp

## Представления и материализованные представления

**Цель дня:** Изучение работы с виртуальными таблицами (Views) и материализованными представлениями (Materialized Views) в PostgreSQL.

## Упражнения

### Упражнение 00 — Создание представлений по полу
**Задача:** Создать два представления для фильтрации людей по полу: `v_persons_female` и `v_persons_male`

### Упражнение 01 — Объединение представлений
**Задача:** Объединить имена людей из двух представлений в один список с сортировкой по имени

### Упражнение 02 — Генерация дат в представлении
**Задача:** Создать представление `v_generated_dates` с датами с 1 по 31 января 2022 года

### Упражнение 03 — Поиск пропущенных дней
**Задача:** Найти дни января 2022, когда никто не посещал пиццерии, используя представление с датами

### Упражнение 04 — Симметричная разность множеств
**Задача:** Реализовать формулу `(R - S)∪(S - R)` для визитов 2 и 6 января 2022 в представлении `v_symmetric_union`

### Упражнение 05 — Расчет скидочных цен
**Задача:** Создать представление `v_price_with_discount` с информацией о заказах и ценами со скидкой 10%

### Упражнение 06 — Материализованное представление
**Задача:** Создать материализованное представление `mv_dmitriy_visits_and_eats` для поиска бюджетных визитов Dmitriy

### Упражнение 07 — Обновление материализованного представления
**Задача:** Добавить новый визит Dmitriy и обновить материализованное представление

### Упражнение 08 — Очистка базы данных
**Задача:** Удалить все созданные представления и материализованные представления

## Технические требования

- **Язык:** ANSI SQL
- **СУБД:** PostgreSQL
- **Основные концепции:**
  - **Представления (Views)** - виртуальные таблицы, обновляемые автоматически
  - **Материализованные представления** - физические копии данных, требующие обновления
  - Работа с множествами и операциями над ними
  - Генерация последовательностей дат

**Примечание:** Все решения представлены в отдельных SQL-файлах. Упражнения продолжают использовать изменения данных из предыдущих дней.
