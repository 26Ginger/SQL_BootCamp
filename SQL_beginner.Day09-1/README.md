## Технические требования

- **Язык:** SQL, PL/pgSQL
- **СУБД:** PostgreSQL
- **Основные концепции:**
  - **Триггеры** - автоматическое выполнение кода при DML операциях
  - **Функции** - повторно используемые блоки кода
  - **PL/pgSQL** - процедурное расширение PostgreSQL
  - **Аудит** - отслеживание изменений данных

## Типы функций:

### SQL функции:
- Простые, на чистом SQL
- Быстрые для простых операций
- Подходят для запросов к данным

### PL/pgSQL функции:
- Сложная логика с переменными, циклами, условиями
- Подходят для бизнес-логики
- Более гибкие, но медленнее

## Структура триггера:

```sql
CREATE OR REPLACE FUNCTION fnc_trg_example() 
RETURNS TRIGGER AS $$
BEGIN
    -- логика триггера
    RETURN NEW; -- или OLD
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_example
    AFTER INSERT ON table_name
    FOR EACH ROW
    EXECUTE FUNCTION fnc_trg_example();
```    

**Примечание:** Все решения должны быть представлены в отдельных SQL-файлах.
