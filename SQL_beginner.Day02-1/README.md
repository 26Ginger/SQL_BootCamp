# Day 02 — SQL Bootcamp

## Продвинутая работа с JOIN в SQL

**Цель дня:** Глубокое изучение различных типов JOIN-операций и сложных запросов для анализа данных.

## Упражнения

### Упражнение 00 — LEFT/RIGHT JOIN
**Задача:** Найти пиццерии с рейтингом, которые никто не посещал (без IN/EXISTS/UNION)

### Упражнение 01 — Поиск пропущенных дат
**Задача:** Найти дни с 1 по 10 января 2022, когда люди с ID 1 или 2 не посещали пиццерии (используя generate_series)

### Упражнение 02 — FULL JOIN
**Задача:** Создать полный список людей и пиццерий за период 1-3 января 2022, заменяя NULL на '-'

### Упражнение 03 — CTE (Common Table Expressions)
**Задача:** Переписать запрос из упр.01 с использованием CTE для генерации дней

### Упражнение 04 — Поиск пицц
**Задача:** Найти все пиццерии и цены на mushroom или pepperoni пиццу с сортировкой

### Упражнение 05 — Анализ данных людей
**Задача:** Найти имена женщин старше 25 лет с сортировкой по имени

### Упражнение 06 — Любимые пиццы
**Задача:** Найти все пиццы, заказанные Denis или Anna, с названиями пиццерий

### Упражнение 07 — Бюджетный визит
**Задача:** Найти пиццерию, которую Dmitriy посетил 8 января 2022 с пиццей дешевле 800 рублей

### Упражнение 08 — Анализ заказов
**Задача:** Найти мужчин из Москвы или Самары, которые заказывали pepperoni или mushroom пиццу

### Упражнение 09 — Любители двух видов пиццы
**Задача:** Найти женщин, которые заказывали и pepperoni, и cheese пиццу

### Упражнение 10 — Соседи
**Задача:** Найти людей, живущих по одному адресу, с выводом пар имен

## Технические требования

- **Язык:** ANSI SQL
- **СУБД:** PostgreSQL
- **Особенности:**
  - Работа с различными типами JOIN (LEFT, RIGHT, FULL)
  - Использование CTE (Common Table Expressions)
  - Генерация последовательностей дат (generate_series)
  - В некоторых заданиях ограничено использование IN, EXISTS, UNION
- **Сортировка:** Результаты должны быть упорядочены согласно условиям задач
- **Форматирование:** Замена NULL значений на '-' в определенных случаях

**Примечание:** Все решения представлены в отдельных SQL-файлах с соответствующими названиями.
