# Day 00 — SQL Bootcamp

## Реляционная модель данных и SQL

**Цель дня:** Изучение основ реляционной модели и базовых конструкций SQL для получения данных.

## Структура базы данных

![Схема базы данных](misc/images/schema.png)

**Основные таблицы:**
- `pizzeria` - список пиццерий с рейтингом
- `person` - информация о людях (имя, возраст, пол, адрес)
- `menu` - меню пиццерий с ценами
- `person_visits` - визиты в пиццерии
- `person_order` - заказы пиццы

## Упражнения

### Упражнение 00
**Задача:** Вывести имена и возраст всех людей из города 'Kazan'

### Упражнение 01  
**Задача:** Вывести имена и возраст женщин из города 'Kazan' с сортировкой по имени

### Упражнение 02
**Задача:** Вывести список пиццерий с рейтингом от 3.5 до 5 двумя способами:
- С использованием операторов сравнения (<=, >=)
- С использованием BETWEEN

### Упражнение 03
**Задача:** Найти ID людей (без дубликатов), которые посещали пиццерии с 6 по 9 января 2022 или пиццерию с ID=2

### Упражнение 04
**Задача:** Создать вычисляемое поле в формате: `Имя (age:возраст,gender:'пол',address:'адрес')`

### Упражнение 05
**Задача:** Найти имена людей, которые заказывали меню с ID 13, 14, 18 7 января 2022 (без использования IN и JOIN)

### Упражнение 06
**Задача:** Добавить проверку имени - возвращать true если имя 'Denis', иначе false

### Упражнение 07
**Задача:** Классифицировать людей по возрастным интервалам:
- 10-20 лет: 'interval #1'
- 21-23 года: 'interval #2'  
- остальные: 'interval #3'

### Упражнение 08
**Задача:** Вывести все заказы с четными ID, отсортированные по ID

### Упражнение 09
**Задача:** Вывести имена людей и названия пиццерий для визитов с 7 по 9 января 2022 (без JOIN)

## Технические требования

- **Язык:** ANSI SQL
- **СУБД:** PostgreSQL
- **Ограничения:** В некоторых заданиях запрещены IN и JOIN
- **Сортировка:** Результаты должны быть упорядочены согласно условиям задач

**Примечание:** Все решения представлены в отдельных SQL-файлах с соответствующими названиями.
