# Day 07 — SQL Bootcamp

## Агрегация данных и аналитические запросы

**Цель дня:** Изучение OLAP-конструкций для анализа данных и получения сводной информации.

## Упражнения

### Упражнение 00 — Базовая агрегация
**Задача:** Найти количество визитов каждого человека в пиццерии с сортировкой

### Упражнение 01 — Топ посещений с именами
**Задача:** Вывести топ-4 людей по количеству визитов с реальными именами

### Упражнение 02 — Статистика ресторанов
**Задача:** Создать объединенный список топ-3 пиццерий по визитам и заказам

### Упражнение 03 — Суммарная статистика
**Задача:** Объединить статистику визитов и заказов по пиццериям с суммарным подсчетом

### Упражнение 04 — Фильтрация групп
**Задача:** Найти людей с более чем 3 визитами (без использования WHERE)

### Упражнение 05 — Уникальные клиенты
**Задача:** Найти уникальные имена людей, которые делали заказы (без GROUP BY и UNION)

### Упражнение 06 — Метрики ресторанов
**Задача:** Рассчитать количество заказов, среднюю, максимальную и минимальную цены для каждой пиццерии

### Упражнение 07 — Средний рейтинг
**Задача:** Вычислить общий средний рейтинг всех пиццерий

### Упражнение 08 — Локальные заказы
**Задача:** Проанализировать заказы по адресам людей и ближайшим пиццериям

### Упражнение 09 — Сложные вычисления
**Задача:** Выполнить агрегацию по адресам с формулой "Макс возраст - (Мин возраст / Макс возраст)"

## Технические требования

- **Язык:** ANSI SQL
- **СУБД:** PostgreSQL
- **Основные концепции:**
  - **Агрегатные функции** (COUNT, AVG, MAX, MIN)
  - **Группировка данных** (GROUP BY)
  - **Фильтрация групп** (HAVING)
  - **Сортировка результатов** (ORDER BY)
  - **Округление чисел** (ROUND)
  - **Объединение запросов** (UNION)

## Особые ограничения:

- В упр.04 запрещено использовать WHERE
- В упр.05 запрещены GROUP BY и операции с множествами
- Требуется точное округление до указанного количества знаков

**Примечание:** Все решения должны быть представлены в отдельных SQL-файлах. Упражнения продолжают использовать расширенную модель данных с предыдущих дней.
