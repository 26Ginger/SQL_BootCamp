# Day 06 — SQL Bootcamp

## Улучшение клиентского опыта и модели данных

**Цель дня:** Расширение модели данных для реализации системы персональных скидок и улучшение целостности данных.

## Упражнения

### Упражнение 00 — Создание таблицы скидок
**Задача:** Создать таблицу `person_discounts` для хранения персональных скидок с внешними ключами на людей и пиццерии

### Упражнение 01 — Назначение персональных скидок
**Задача:** Заполнить таблицу скидок на основе истории заказов с расчетом размера скидки по количеству заказов

### Упражнение 02 — Расчет цен со скидкой
**Задача:** Написать запрос для отображения заказов с исходной ценой и ценой со скидкой

### Упражнение 03 — Уникальный индекс
**Задача:** Создать многоколоночный уникальный индекс для предотвращения дубликатов пар человек-пиццерия

### Упражнение 04 — Ограничения целостности данных
**Задача:** Добавить constraints для колонок таблицы скидок:
- NOT NULL ограничения
- Значение по умолчанию 0%
- Ограничение диапазона 0-100%

### Упражнение 05 — Комментарии для документации
**Задача:** Добавить комментарии к таблице и колонкам для документирования бизнес-логики

### Упражнение 06 — Автоматическая генерация ID
**Задача:** Создать sequence для автоматической генерации первичных ключей в таблице скидок

## Технические требования

- **Язык:** SQL (DDL, DML)
- **СУБД:** PostgreSQL
- **Основные концепции:**
  - Создание и модификация таблиц (DDL)
  - Вставка данных на основе агрегации (DML)
  - Ограничения целостности (CONSTRAINTS)
  - Последовательности (SEQUENCE)
  - Индексы для производительности
  - Документирование через комментарии

## Бизнес-логика скидок:

| Количество заказов | Размер скидки |
|-------------------|---------------|
| 1                 | 10.5%         |
| 2                 | 22%           |
| 3+                | 30%           |

**Примечание:** Все решения представлены в отдельных SQL-файлах. Упражнения продолжают использовать изменения данных из предыдущих дней.
