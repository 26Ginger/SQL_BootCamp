# Day 01 — SQL Bootcamp

## Работа с множествами и JOIN в SQL

**Цель дня:** Изучение операций с множествами и базовых JOIN-операций для объединения данных из разных таблиц.

## Упражнения

### Упражнение 00 — Объединение данных
**Задача:** Создать общий список из идентификаторов и имен меню и людей с сортировкой по ID и имени

### Упражнение 01 — UNION с подзапросом
**Задача:** Модифицировать предыдущий запрос - убрать ID и отсортировать имена людей, затем названия пицц

### Упражнение 02 — Уникальные названия пицц
**Задача:** Найти уникальные названия пицц (без DISTINCT/GROUP BY/JOIN) и отсортировать по убыванию

### Упражнение 03 — Общие даты визитов и заказов
**Задача:** Найти даты, когда люди одновременно посещали пиццерии и делали заказы (без JOIN)

### Упражнение 04 — Разность множеств
**Задача:** Найти разницу person_id между заказами и визитами на 7 января 2022 (без JOIN)

### Упражнение 05 — Декартово произведение
**Задача:** Создать все возможные комбинации людей и пиццерий

### Упражнение 06 — Имена вместо ID
**Задача:** Модифицировать запрос из упр.03 - выводить имена людей вместо ID

### Упражнение 07 — JOIN заказов и людей
**Задача:** Объединить даты заказов с информацией о людях в формате "Имя (age:возраст)"

### Упражнение 08 — NATURAL JOIN
**Задача:** Переписать предыдущий запрос с использованием NATURAL JOIN

### Упражнение 09 — IN vs EXISTS
**Задача:** Найти пиццерии без визитов двумя способами:
- С использованием IN
- С использованием EXISTS

### Упражнение 10 — Комплексный JOIN
**Задача:** Вывести список людей, названия заказанных пицц и пиццерий с сортировкой по трем колонкам

## Технические требования

- **Язык:** ANSI SQL
- **СУБД:** PostgreSQL
- **Особенности:** 
  - Работа с операторами множеств (UNION, EXCEPT, INTERSECT)
  - Изучение разных типов JOIN
  - В некоторых заданиях ограничено использование определенных конструкций
- **Сортировка:** Результаты должны быть упорядочены согласно условиям задач

**Примечание:** Все решения представлены в отдельных SQL-файлах с соответствующими названиями.
